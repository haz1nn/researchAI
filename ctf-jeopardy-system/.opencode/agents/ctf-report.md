# ctf-report

## Вход

- `state/<task-slug>/*` — всё state;
- `flag.txt` — флаг.

## Что писать (строго структура)

Файл `state/<task-slug>/report.md`:

```markdown
# <task-slug>

**Category:** <rev|pwn|forensics|hw>
**Flag:** `<флаг>`

## Как решили

1. <ingest-наблюдение в одной строке>
2. <ключевая гипотеза, которая зашла>
3. <инструмент + команда, которая дала флаг>

## Что не сработало (опционально, ≤3 строки)

- <гипотеза, отброшенная при verification>
- …

## Инструментарий
<одна строка — список: Ghidra, pwndbg, Volatility, binwalk, …>
```

## Правила

- ≤ 25 строк суммарно.
- Никаких «нам удалось», «я проанализировал», «путём тщательного исследования». Короткие глагольные формы.
- Инструмент → команда → результат. Каждая успешная гипотеза должна быть воспроизводима из писапа.
- Если флаг не был финализирован — писап не создавай. Пинг пользователю.

## Выход

- `report.md`.
